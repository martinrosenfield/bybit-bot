## Семантика журнала

- DRY_RUN — только расчёт сигнала; методы изменения биржевого состояния не вызываются.
- ORDER_ACCEPTED — биржа приняла заявку, исполнение ещё не подтверждено.
- ENTRY — найдены Trade-исполнения именно этого orderId, символа и стороны, полный объём, проверена соответствующая one-way позиция и точное совпадение server stopLoss/takeProfit. Цена в ENTRY — средняя по фактическим исполнениям, execution_ids сохраняются.
- Любой timeout/исключение после резервирования, частичное исполнение, несовпадение стопов или отсутствие подтверждения оставляют pending и блокируют символ в halted; ACTION_REQUIRED. Повторная отправка с тем же ID запрещена.

Резервирование с устойчивым orderLinkId записывается атомарно с fsync до передачи ордера. Дневной anchor и halt_day переживают перезапуск; pending при старте блокирует соответствующий символ. Один экземпляр защищён flock. Свечи фильтруются по серверному времени. В dry-run preflight не меняет плечо. Точный endpoint ограничен api-demo.bybit.com.
