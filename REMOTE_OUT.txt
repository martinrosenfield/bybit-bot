# Обмен Claude ↔ ChatGPT/Codex

## Правила (для обоих помощников)
1. **Перед работой** прочитай `ЖУРНАЛ.md` (последние 10–15 записей) и файл нужного проекта в `проекты/`.
2. **После работы** допиши в `ЖУРНАЛ.md` одну запись в конец (не правь чужие записи):
   `## 2026-10-26 09:40 МСК — Claude | Трейдинг` → что сделано, что проверено, открытые вопросы, следующий шаг.
3. **Файл проекта** (`проекты/*.md`) — это текущее состояние, а не история. Обновляй разделы «Статус», «Решения», «Следующие шаги»; старое переноси в журнал, а не удаляй молча.
4. Задачи друг другу — в `ЗАДАЧИ.md` с пометкой `[для Claude]` / `[для ChatGPT]`; выполнивший ставит `[x]` и пишет итог в журнал.
5. Не храни здесь ключи API, пароли, токены, номера карт и паспортные данные.
6. Не объявляй обмен «автоматическим»: каждый помощник видит файлы, только когда сам их читает.
7. Подробные рабочие файлы остаются в папках проектов (`../Трейдинг`, `../ГНБ`, `../авито`, `../Сервис по возвратам`); здесь — ссылки на них и выводы.

# ПРОКОЛ — локальный отбор закупок ГНБ и ИД

Лёгкая программа без внешних библиотек и подписок. Основной источник — ЕИС zakupki.gov.ru. В файле `eis-snapshot-2026-10-26.json` сохранены 20 реальных карточек из первых страниц двух запросов ЕИС на 26.10.2026; это снимок выдачи, без проверки ТЗ и возможности субподряда. Учебные карточки добавляются только отдельной кнопкой и помечены.

## Запуск

Дважды нажмите **Запустить.command**, затем откройте **http://127.0.0.1:8765**. Окно терминала нужно оставить открытым; остановка — Control+C. Нужен Python 3 (на этом компьютере он обнаружен). Программа слушает только 127.0.0.1.

Для работы без сервера откройте **index.html** в браузере. Доступны ручной ввод, импорт, отбор и резервные копии; прямая загрузка RSS требует сервера. Базы при открытии через файл и через localhost могут различаться: для переноса используйте JSON.

## Как использовать

1. Выберите запрос и нажмите «Загрузить из ЕИС» для получения RSS или «Открыть ЕИС» для просмотра выдачи на сайте. По умолчанию ищется стадия подачи заявок по 44-ФЗ и 223-ФЗ. Если ЕИС не открывается, проверьте доступ к сайту отдельно в браузере.
2. Скопируйте название и текст извещения / ТЗ в «Добавить закупку». Добавьте ссылку, место работ, срок и цену при наличии. Более полный текст даёт более содержательный разбор.
3. Вкладки разделяют проколы с трубой и исполнительную документацию. Для ИД задана вся Россия. Регион ГНБ можно указать в фильтре; совпадение по части названия. Неустановленный регион остаётся для проверки. Во вкладке ИД записи с обоими направлениями сохраняются независимо от региона ГНБ.
4. Откройте «Разобрать закупку»: там причины отбора, исходные фрагменты и вопросы для обсуждения с основным подрядчиком. Можно сохранить заметки и избранное.
5. Для переноса и резервной копии выгрузите JSON, затем импортируйте его в другом браузере. Файл содержит карточки и заметки. Импорт объединяет карточки по номеру, ссылке либо названию с заказчиком; не очищает существующую базу. Настройку региона при переносе задайте снова.

## Поддерживаемые файлы

- CSV UTF-8: колонки «Название», «Номер», «Регион», «Заказчик», «Цена», «Срок», «Ссылка», «Текст». Разделитель `;` или `,`; поддерживаются кавычки и многострочные поля. Срок — `ГГГГ-ММ-ДД`. В интерфейсе есть пустой шаблон.
- JSON: массив объектов с полями `title`, `text`, `region`, `customer`, `price`, `deadline`, `id`, `url`; либо резервная копия программы.
- TXT: текст открывается в редакторе новой карточки, нужно проверить название и сохранить.
- XML/RSS: RSS или Atom. Произвольная XML-выгрузка ЕИС не поддерживается.
- HTML: сохранённая страница ЕИС. Парсер пытается выделить блоки выдачи; при неизвестной структуре добавляет текст страницы одной карточкой. Проверьте результат. Цена, место работ, заказчик и срок автоматически из HTML/RSS не извлекаются: заполните их после проверки источника.

До 8 МБ и 2000 карточек в одном импортируемом файле. PDF, DOCX, XLSX и ZIP автоматически не разбираются; скопируйте нужный текст из документов. Исходные документы сохраняйте отдельно.

## Прямая загрузка из ЕИС

Кнопка «Загрузить из ЕИС» делает один запрос к публичному RSS по выбранной фразе, не ко всей базе и не к файлам ТЗ. Сервер не принимает произвольные внешние адреса, не требует ключей и не отключает проверку TLS. Фоновое сканирование и автоматические уведомления не включены.

**Проверка 26.10.2026:** первые запросы curl вернули HTTP 404, но обычный браузер открыл ЕИС, а запрос через локальный сервер программы успешно загрузил 50 записей RSS по слову «ГНБ». Путь RSS и параметры поиска сверены с интерфейсом ЕИС. Из анализа исключается служебная часть RSS с поисковой фразой; отдельно извлекаются наименование объекта закупки, заказчик и цена. Короткий запрос «ГНБ» может находить сокращения названий организаций, поэтому по умолчанию выбран полный запрос про бурение. Доступность ЕИС может меняться; при ошибке сохраняется старая база. Полный охват базы не обеспечивается.

## Границы оценки

- ИД из предыдущего образца в папке проекта — демонстрационное оформление, а не комплект фактической исполнительной документации для сдачи.
